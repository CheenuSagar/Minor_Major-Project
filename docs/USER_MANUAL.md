# NextStore User Manual & Operational Guide

## Quick Start
1. Start the database backend: Double click `run-mysql.bat`.
2. Open your web browser: Navigate to `http://localhost:8080`.
3. Default Login Credentials:
   - Store Manager: `manager` / `Manager@123`
   - Customer: `customer` / `Customer@123`

## Workspaces
- **Customer**: Browse items, add to cart, and generate UPI QR for self-checkout.
- **Cashier**: Scan items with camera barcode reader or type SKU, select Cash/UPI/Card tender, print receipt.
- **Store Manager**: Add new products, adjust inventory quantities, and review low-stock warnings.
- **Store Owner**: Review gross margins, revenue projections, and AI reorder recommendations.
