# NextStore UI & Design System Specification

## Brand Name
**NextStore**
Tagline: *Smarter Billing, Faster Retail*

## Color Palette (Light Mode)
- Background: `#f8fafc` / `#ffffff`
- Primary Accent: `#dc2626` (Crimson Red)
- Primary Hover: `#b91c1c`
- Card Background: `#ffffff`
- Text Primary: `#0f172a`
- Text Secondary: `#475569`
- Border: `#e2e8f0`

## Typography
- Font Family: `Inter`, system-ui, -apple-system, sans-serif
- Weights: 400 (Regular), 500 (Medium), 600 (Semi-bold), 700 (Bold)

## Header Bar
Includes store logo, live clock display, and connection status indicator.

## Header Styling
Sticky top with backdrop blur filter (`backdrop-filter: blur(12px)`).

## Navigation Transitions
Subtle 0.2s cubic-bezier transitions on hover and active navigation states.

## Card Elevation
Soft shadows: `box-shadow: 0 4px 6px -1px rgb(0 0 0 / 0.05), 0 2px 4px -2px rgb(0 0 0 / 0.05)`
Border radius: `1rem` (16px).

## Button Micro-Styles
Primary action buttons with active depression scaling (`transform: scale(0.98)`).

## Stock Pills
- In Stock: Green (`#16a34a`)
- Low Stock: Amber (`#d97706`)
- Out of Stock: Red (`#dc2626`)

## Scrollbar Styling
Custom slim scrollbar matching light mode theme aesthetic.
