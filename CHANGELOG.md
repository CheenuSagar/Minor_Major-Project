# NextStore Changelog

## [2.0.0] - 2026-11-20
### Added
- MySQL 8.0 database persistence layer with HikariCP connection pooling
- Modern high-contrast Light Mode user interface with Crimson Red branding
- 4 Role-based workspaces: Customer, Cashier, Store Manager, and Store Owner
- Hardware HTML5 camera barcode scanner with Web Audio API synthetic beep
- Dynamic UPI QR code generation supporting GPay, PhonePe, Paytm, and BHIM
- Promotional coupon engine supporting FLAT50, SAVE10, NEXTSTORE20, and SUPERMCA
- WhatsApp and SMS digital receipt sharing with formatted invoice text
- AI Inventory Demand Forecaster with velocity tiers and runout estimation
- 1-click execution scripts (`run-mysql.bat` and `run.bat`)
- Complete engineering documentation in `docs/`
